\begin{abstract}
A common recipe for LLM scientific agents is to let the model propose hypotheses and let trusted
machinery verify them. The recipe works, but it is rarely asked how much of the result the model
is responsible for. We build such a system for active causal discovery and measure that directly.
\nem{} confines the LLM to one job --- naming which adjacencies a statistical estimator probably
got wrong --- and hands everything numerical to exact machinery: a Bayesian score ranks the
candidate graphs those edits generate, expected information gain chooses each intervention, and a
closed-form likelihood updates the belief. It works well: $0.956$ directed-edge F1 against
$0.874$ for the strongest classical active baseline ($+0.082$, $p{=}0.0002$, $80$ paired
instances) and $0.000$--$0.202$ for the same models run end-to-end, at one LLM call and $30\times$
fewer tokens. Then we replace the model with a control that proposes edits uniformly at random,
and the gap disappears: $0.951$ against $0.956$ ($p{=}0.68$). The advantage over the classical
baseline is also narrower than the headline suggests: it is concentrated on the graph size where
the estimator is weakest, falling to $+0.017$--$+0.030$ once that size is excluded. Across five proposers spanning a
$4.2\times$ range in how often their edits are correct ($7.9\%$ to $32.8\%$), downstream accuracy
moves by $0.026$ and does not order the models the way proposal quality does. What is load-bearing
is the scaffolding: the Bayesian update is worth $0.29$ F1, and a guard that reserves part of the
hypothesis budget for the unedited estimate is worth $0.056$ --- twice the spread between the best
and worst model, and free when the proposal is perfect. The LLM earns its keep only where two
conditions hold together: the estimator must be underpowered \emph{and} the variables must carry
real names, where the best proposer beats the random control by $0.080$ ($p{=}0.0001$). Since
perfect edits would gain $0.097$, the channel is real and largely unclaimed.
\end{abstract}

\section{Introduction}
\label{sec:intro}

Propose-and-verify is becoming the default architecture for LLM scientific agents: the model
generates candidate hypotheses, trusted machinery checks them, and only checked results survive.
The appeal is that the verifier bounds the damage a wrong generation can do, so an unreliable
model becomes usable. That argument is sound. What it does not establish is how much the model
contributed, because the usual evidence for the architecture is an end-to-end score against a
baseline that has neither the model nor the verifier.

The missing control is the one that holds the verifier fixed and replaces the model with something
that cannot possibly know anything. If a system with an LLM proposer and a system with a random
proposer score the same, then the architecture is doing the work, and reporting the result as
evidence that the model understood the domain is a mistake. We run that control.

\emph{Active causal discovery} lets us run it cleanly. Observational data cannot distinguish
$A \to B$ from $B \to A$; interventions can. An agent gets a sample of observational data and a
budget of a few experiments, and must return the directed graph. The task is small enough that the
exact Bayesian solution is computable, so the verifier is not an approximation we have to trust,
and every stage --- what was proposed, what survived scoring, what the experiments settled --- is
separately measurable. We anonymize the variables as $X_0 \dots X_{d-1}$ so that nothing can be
recalled from world knowledge, then deliberately put real names back as a measured condition.

Our companion study, \rauma{}, established what an LLM should \emph{not} do here: given authority
to state the graph from experimental evidence it loses $0.32$ F1, because these models cannot
judge whether a measured mean has moved relative to its sampling scale. This paper asks the
constructive follow-up --- if the model should not decide, is proposing a job it can do? --- and
answers it with the control that makes the answer interpretable.

\paragraph{Contributions.}
\begin{itemize}\itemsep1pt
\item \textbf{A system that works.} \nem{} reaches $0.956$ and $0.953$ directed F1 for two models
against $0.874$ for the strongest classical active baseline ($p \le 0.0002$, paired over $80$
instances), and beats the same models run end-to-end by $0.75$--$0.96$ F1 using one LLM call and
$30\times$ fewer tokens (Section~\ref{sec:main}).
\item \textbf{The control that reframes it.} A uniformly random editor, given the same pipeline,
scores $0.951$ --- indistinguishable from either language model ($p{=}0.68$, $p{=}0.90$). Across
five proposers whose edits are correct between $7.9\%$ and $32.8\%$ of the time, final accuracy
varies by $0.026$ and does not track proposal quality (Section~\ref{sec:credit}).
\item \textbf{Where the credit belongs.} Holding the candidate set fixed, the Bayesian update is
worth $0.29$ F1, choosing experiments by information gain rather than at random $0.06$, and a
guard that reserves half the hypothesis budget for the unedited estimate $0.056$ --- while costing
a perfect proposer exactly nothing (Section~\ref{sec:mechanism}).
\item \textbf{When the proposer does earn its keep.} Only where the estimator is underpowered
\emph{and} the variables are named: on published DAG structures at $n_{\mathrm{obs}}{=}60$,
\texttt{gemini-3-flash} beats the random control by $0.080$ ($p{=}0.0001$), and naming alone is
worth $0.024$ F1 pooled across five models ($p{=}0.003$). Perfect edits would gain $0.097$ in the
main regime, so the channel is real and mostly unclaimed (Section~\ref{sec:when}).
\end{itemize}

\section{Background, in plain terms}
\label{sec:background}

Formal statements are in Appendix~\ref{app:background}; this section is enough to read the
results.

\paragraph{What observation cannot tell you.}
Suppose $d$ variables are generated by an unknown directed acyclic graph (DAG), each variable a
noisy linear function of its parents. Observational data reveal which pairs are \emph{directly
connected} --- the \emph{skeleton} --- and the direction of some edges but not all. The graphs
that remain indistinguishable form an \emph{equivalence class}. Orienting what it leaves open is
what experiments are for: forcing $X_a$ to an unusual value shifts the distribution of $a$'s true
children and of nothing else, which settles the edges next to $a$.

\paragraph{What the agent must supply.}
A \emph{candidate set} $\Hyp$ of graphs it considers possible, and a policy for spending
interventions. $\Hyp$ is the ceiling: if the true graph is not in it, no experiment recovers it.
That is why we put the model there.

\paragraph{The estimator being corrected.}
We build the initial skeleton with PC, a standard algorithm that drops an adjacency when two
variables look conditionally independent. With finite samples its tests are underpowered, so it
misses real edges: on our instances it reaches skeleton F1 $0.947$, and the true DAG lies in the
equivalence class it estimates only $45\%$ of the time. Competent, but wrong often enough that
there is something for a proposer to fix.

\paragraph{1. Propose (the only LLM call).}
The model receives the correlation matrix, the partial correlation of every pair given all other
variables, PC's adjacency set, and the currently non-adjacent pairs. It returns adjacencies to
remove and pairs to add, at most four each. It is told the governing fact --- in a linear-Gaussian
DAG two variables are directly connected exactly when their partial correlation given the rest is
non-zero --- and that an empty list is a valid answer. It never sees interventional data. Prompts
are in Appendix~\ref{app:prompts}.

\paragraph{2. Enumerate and score.}
Let $S$ be PC's skeleton. We form $S$, the all-edits variant, and each single edit, and enumerate
acyclic orientations of each (exhaustively when cheap, sampled otherwise). Every candidate is
fitted by least squares and scored by linear-Gaussian BIC on the same observational sample, giving
$w_h \propto \exp(-\tfrac12\mathrm{BIC}_h)$ over a candidate set $\Hyp$ of at most $48$ graphs.

\emph{The guard.} Half of $|\Hyp|$ is reserved for the best-scoring orientations of the
\emph{unedited} skeleton before any edited variant is admitted, so a proposal can only add
candidates and never evict what the statistics already supported. This turns out to be the
component that matters most about how proposals are handled (Section~\ref{sec:mechanism}).

\paragraph{3. Choose.}
For each variable still ambiguous under $w$, we estimate the expected information gain of
intervening on it about the hypothesis index by Monte Carlo over $12$ simulated outcomes, and
intervene on the maximizer. This is the exact Bayesian design criterion for this model class.

\paragraph{4. Update and submit.}
The interventional batch is scored under each candidate's mutilated linear-Gaussian likelihood in
closed form and $w$ is multiplied through. The loop stops when the budget is spent or
$\max_h w_h > 0.999$; the MAP graph is submitted.

\section{Experimental setup}
\label{sec:setup}

\paragraph{Instances.}
Four graph sizes, $d \in \{4,6,8,10\}$ with $|E| = d$ edges, twenty accepted instances each:
$80$ paired instances. An instance is rejected unless its equivalence class leaves at least two
undirected edges, those edges do not all meet at one node, the skeleton is connected, and at least
one intervention is required; edge weights are drawn away from zero so the model is faithful. The
default sample is $n_{\mathrm{obs}} = 300$ observational rows and $n_{\mathrm{int}} = 150$ per
intervention, and the budget is $|I^*| + 1$ for a minimum identifying set $I^*$ --- on average
$2.8$ experiments. Variables are randomly permuted and named $X_0 \dots X_{d-1}$.
Appendix~\ref{app:instances} has the ladder.

\paragraph{Arms.}
Every arm runs on every instance, so all comparisons are paired. \emph{Baselines}: an oracle
ceiling; \texttt{PC+greedy}, the classical active baseline that intervenes on the highest-degree
ambiguous node and orients by a mean-shift test (with and without Meek closure); and
\texttt{LLM-e2e}, the same models given raw data and full control of the loop.
\emph{Proposal-content arms} share \nem's entire decision layer and differ only in where the edits
come from: \texttt{no-edits} (orientations of PC's unedited skeleton), \texttt{random-edits} (the
same number of removals and additions, drawn uniformly from the same pairs), \texttt{perfect-edits}
(exactly PC's skeleton errors), plus \texttt{MEC-only}, \texttt{LLM-graphs} (the model writes whole
DAGs) and \texttt{random-DAGs}. \emph{Decision-layer arms} hold the candidate set fixed and remove
one mechanism at a time, including \texttt{no-guard}, which lets proposals compete for every
hypothesis slot.

\paragraph{Models and protocol.}
Five proposers spanning roughly two orders of magnitude of price: \texttt{qwen3-coder-30b},
\texttt{gpt-4o-mini}, \texttt{gpt-5.4-mini}, \texttt{claude-haiku-4.5} and
\texttt{gemini-3-flash}, at temperature zero with forced tool calls; full identifiers in
Appendix~\ref{app:instances}. Within an instance every ablation arm replays one shared proposal,
so arms differ only in the component under test. Error bars are $95\%$ CIs, over instances for arm
means and over paired differences for contrasts; pairwise claims use two-sided Wilcoxon
signed-rank tests with win/loss counts. The study is $11{,}700$ episodes.

\emph{Proposal audit.} For every episode we record whether each proposed edit was correct against
the ground-truth skeleton --- a removal is correct if PC's adjacency was spurious, an addition if
the pair really is adjacent. This is what ``edits correct'' means throughout.

\section{Results}
\label{sec:results}

\subsection{The system works}
\label{sec:main}

Table~\ref{tab:main} and Figure~\ref{fig:main}(a) give the headline. \nem{} reaches $0.956$
directed F1 with \texttt{gpt-4o-mini} and $0.953$ with \texttt{qwen3-30b}, against $0.874$ for
\texttt{PC+greedy+Meek} ($+0.082$, $95\%$ CI $[+0.041,+0.127]$, $p{=}0.0002$, W/L $26/8$; and
$+0.079$, $p{=}3.7\times10^{-5}$). Against the same models run end-to-end on the same instances the
gap is $+0.956$ and $+0.750$: an unscaffolded \texttt{gpt-4o-mini} submits no correct arrow in any
of $80$ episodes.

\paragraph{Where the advantage actually sits.}
The headline pools four graph sizes and should not be read as a uniform gain. Broken out, the
advantage over \texttt{PC+greedy+Meek} is $+0.28$ at $d{=}4$ and between $-0.03$ and $+0.05$ at
$d \in \{6,8,10\}$; pooled over $d \ge 6$ it is $+0.017$ (n.s.) for \texttt{gpt-4o-mini} and
$+0.030$ ($p{=}0.03$) for \texttt{qwen3-30b}. This tracks one variable: PC's skeleton F1 is
$0.909$ at $d{=}4$ against $0.94$--$0.97$ at the larger sizes, and the true DAG lies in the class
it estimates for only $30\%$ of $d{=}4$ instances. The system's advantage, like everything else in
this paper, is concentrated where the statistical front-end is weakest; per-level numbers are in
Appendix~\ref{app:scaling}.

Two further contrasts matter more than the baselines. Asking the model for whole DAGs instead of
edits costs $0.29$--$0.31$ F1, so the interface, not the model, decides whether a proposal is
usable at all. And \nem{} does not win by spending more of its budget: it is ahead
at every experiment count ($0.844$ against $0.804$ after one intervention, $0.939$ against
$0.875$ after two), and passes what \texttt{PC+greedy+Meek} reaches with its entire budget on
its second experiment (Figure~\ref{fig:main}(b)).

\subsection{The control: the proposer is nearly interchangeable}
\label{sec:credit}

The result above is easy to read as evidence that the model knows something about causal
structure. It is not, and the reason is the arm sitting directly above \nem{} in
Table~\ref{tab:main}.

\paragraph{A random editor does as well.}
\texttt{random-edits} draws the same number of removals and additions uniformly from the same
pairs the model chooses among, and passes them through the identical pipeline. It scores $0.951$,
against $0.956$ and $0.953$ for the two language models: $+0.004$ $[-0.012,+0.023]$, $p{=}0.68$
and $+0.002$ $[-0.021,+0.025]$, $p{=}0.90$. Both models beat the \emph{unedited} skeleton by a
clear margin ($+0.054$, $p{=}0.001$; $+0.052$, $p{=}0.0005$) --- but so does random editing
($+0.050$, $p{=}0.002$). Widening the neighbourhood of PC's skeleton is what produces the gain;
which direction you widen it in barely registers. The same $d{=}4$ concentration applies: pooled
over $d \ge 6$, editing of any kind is worth $-0.005$ (random), $+0.001$ (\texttt{gpt-4o-mini})
and $+0.014$ (\texttt{qwen3-30b}) over not editing. \emph{Perfect} edits, by contrast, are worth
$+0.058$ ($p{<}0.001$) over that same range --- the channel stays open at every graph size, and
neither the model nor the control walks through it.

\paragraph{Four times better proposals, the same answer.}
This is not an artifact of using cheap models. We ran five proposers on the same instances and
audited every edit. How often their edits are correct spans a factor of $4.2$: $7.9\%$ for
\texttt{gpt-4o-mini}, $8.9\%$ for \texttt{qwen3-30b}, $14.4\%$ for \texttt{gpt-5.4-mini}, $20.2\%$
for \texttt{claude-haiku-4.5}, $32.8\%$ for \texttt{gemini-3-flash}. Downstream F1 spans $0.026$
--- from $0.820$ to $0.846$ --- and does not order the models the way precision does (Spearman
$\rho = 0.30$, n.s.; Figure~\ref{fig:credit}(b)). The three most accurate proposers are not the
three best systems.

\paragraph{Why the signal stops propagating.}
The chain from proposal to answer is measurable at every link, and it is the last one that breaks.
Better proposers do recover more of PC's missing adjacencies ($22\%$ for \texttt{gpt-4o-mini},
$48\%$ for \texttt{gemini-3-flash}) and do put the true DAG in the candidate set more often
($16.7\%$ against $8.3\%$ with no edits). But the best F1 \emph{available in} the candidate set
rises only from $0.875$ to $0.884$, and achieved F1 sits about $0.05$ below that ceiling for
everyone. In the data-poor regime the binding constraint is that BIC cannot reliably rank $48$
candidates on $60$ rows, so a better candidate set is not converted into a better answer. Adding
candidates helps because it raises the chance the truth is present at all; improving \emph{which}
candidates you add helps much less.

\subsection{Where the credit belongs}
\label{sec:mechanism}

If the proposer is nearly interchangeable, something else produces the $0.08$ F1 over the classical
baseline. Table~\ref{tab:decision} and Figure~\ref{fig:credit}(c) locate it.

\paragraph{The belief update dominates.}
Without the Bayesian update the system keeps its BIC ranking, performs its experiments, and
ignores the outcomes: $0.662$, a loss of $0.294$. That single mechanism is worth eleven times the
gap between the best and worst proposer. Choosing experiments by expected information gain rather
than at random is worth $0.056$--$0.068$; re-scoring candidates by BIC rather than a uniform prior,
$0.022$. Choosing by information gain rather than by a one-line max-degree heuristic is worth
$0.004$ (n.s.), reproducing our companion study's finding that experiment \emph{selection} is not
where these systems fail.

\paragraph{The guard is worth more than the model.}
Turning off the reservation --- letting proposals compete for every hypothesis slot --- costs
$0.056$ ($[+0.044,+0.069]$, $p{=}1.6\times10^{-9}$, W/L $55/2$) and $0.046$. The reason is visible
in the candidate set: with the guard the true DAG survives in $69\%$ of instances, without it in
$24\%$. The same holds for the random editor ($0.951 \to 0.895$; truth kept $74\% \to 25\%$).
Crucially, the guard costs a \emph{perfect} proposer exactly nothing ($0.999$ either way,
$p{=}1$): it is pure insurance, free when the proposal is right and worth more than any model
choice when it is not (Figure~\ref{fig:mechanism}(a)).

\subsection{When the proposer does earn its keep}
\label{sec:when}

The null result above is conditional, not universal. Two things have to be true before a language
model beats a coin flip here.

\paragraph{Condition 1: the estimator must be underpowered.}
Sweeping the observational sample from $40$ to $1000$ rows moves PC's skeleton F1 from $0.824$ to
$0.968$. The LLM beats the random editor only at the bottom of that range: $+0.044$
$[+0.011,+0.079]$ ($p{=}0.008$) at $n_{\mathrm{obs}}{=}40$, and nothing distinguishable from zero
at $60$, $120$, $300$ or $1000$ (Figure~\ref{fig:when}(a)).

\paragraph{Condition 2: the variables must mean something.}
Anonymizing variables removes exactly the knowledge an LLM is supposed to contribute, so we put it
back. On five published DAG structures re-parameterized as linear-Gaussian models, we run each
proposer twice --- once under the published variable names with a one-sentence domain description,
once as $X_0 \dots X_{d-1}$ --- holding the graph, the parameters, the samples and the node
indices identical, so the only thing that changes is the words.

Names help, and most where the data is scarcest. At $n_{\mathrm{obs}}{=}60$, naming raises edit
precision for four of five models and is worth $+0.024$ F1 pooled ($[+0.006,+0.042]$, $p{=}0.003$,
$300$ paired episodes). This is also the one regime where a language model clearly beats the
control: \texttt{gemini-3-flash} under real names reaches $69\%$ edit precision and $0.768$ F1,
against $0.688$ for the random editor ($+0.080$, $p{=}0.0001$) and $0.652$ with no edits
($+0.116$, $p{=}5\times10^{-7}$); \texttt{qwen3-30b} gains $+0.047$ ($p{=}0.03$). At
$n_{\mathrm{obs}}{=}300$ the pooled naming effect falls to $+0.006$ (n.s.). Neither condition alone
suffices: named variables with plenty of data, and scarce data with anonymized variables, both
leave the model at the level of random editing.

\paragraph{The channel is real and unclaimed.}
Throughout, \texttt{perfect-edits} shows what a proposer could be worth: $0.999$ F1 in the main
regime ($+0.097$ over no edits, $p{=}3\times10^{-8}$) and $0.894$ against $0.652$ on the named
structures. Since fixing the skeleton takes the system to within $0.001$ of the oracle,
\emph{essentially all remaining error is adjacency error}, and the best proposer we measured
captures under half of what is available. This is not an argument that LLM proposals cannot help;
it is a measurement of how much of the available help today's models deliver on this task.

\subsection{Robustness of the null}
\label{sec:robust}

A null result is only as good as the settings it survives. We varied four things that could
plausibly have produced it (Table~\ref{tab:robust}).

\emph{A second axis for front-end quality.} Sample size is not the only way to make PC weaker.
Moving its significance threshold from $\alpha{=}0.01$ to $0.10$ at fixed
$n_{\mathrm{obs}}{=}60$ moves skeleton F1 from $0.810$ to $0.885$, and at all three settings the
LLM remains indistinguishable from the random editor ($-0.022$ to $+0.025$, all n.s.). The null is
not specific to how we made the estimator weak.

\emph{A tight budget.} With slack $0$ the budget is exactly $|I^*|$, so a wasted experiment cannot
be recovered and the selector becomes load-bearing. It does: choosing experiments by information
gain rather than at random is now worth $0.055$--$0.060$ ($p \le 0.002$), while the max-degree
heuristic remains statistically tied with exact EIG ($-0.005$, $+0.003$). \nem{} still beats
\texttt{PC+greedy+Meek} by $0.063$--$0.066$, and still beats the unedited skeleton by
$0.041$--$0.044$.

\emph{The edit budget.} Allowing two, four or eight edits does not produce a monotone gain
($-0.010$, $+0.024$, $+0.014$ over no edits for \texttt{gpt-4o-mini}), and edit precision does not
improve with a larger allowance. More proposals is not the missing ingredient.

\emph{Larger graphs.} At $d{=}12$ all arms are within noise of each other on ten instances. It is
also the size at which our ceiling arm stops being a ceiling: orientations must be sampled rather
than enumerated, so \texttt{perfect-edits} no longer dominates by construction (its best-in-set F1 is
$0.918$, below \nem's $0.941$). We therefore draw no conclusion at $d{=}12$ beyond the
scalability limitation it illustrates.

\subsection{Cost}
\label{sec:cost}

\nem{} makes one forced tool call and spends $1{,}114$ tokens (\texttt{gpt-4o-mini}) or $1{,}807$
(\texttt{qwen3-30b}) per episode, about \$0.0002--\$0.0007. The end-to-end agent spends $3.6$ calls
and $34$k--$51$k tokens for a far worse answer. The difference is structural: an end-to-end agent
carries every interventional batch through its context window, while \nem{} never shows the model
interventional data at all. Given Section~\ref{sec:credit}, the cheapest configuration that matches
\nem{} in the main regime is the one with no model in it.

\section{Related work}
\label{sec:related}

\paragraph{Active causal discovery.}
Choosing interventions to identify a graph has been addressed by coverage arguments over the
equivalence class, information-theoretic acquisition, Bayesian experimental design over structure
posteriors, and learned or amortized acquisition policies. Our decision layer is a textbook
instance of the Bayesian branch rather than a contribution: it is the fixed, exact yardstick
against which the proposal channel is measured.

\paragraph{LLMs and causality.}
Language models have served as semantic causal experts answering pairwise cause-effect questions,
as priors or initializers for structure learning, as search operators over graphs, and as
end-to-end agents. Evaluations typically report a final graph or task score on named variables,
where part of the answer is recoverable from world knowledge, and typically without a model-free
control that holds the rest of the pipeline fixed. The two conditions in Section~\ref{sec:when}
suggest why results in this literature vary so much: the same system can look like a large win or
like nothing depending on whether the variables are named and how strong the statistical front-end
is.

\paragraph{Propose-and-verify.}
Generating many candidates cheaply and filtering with a trusted verifier recurs across program
synthesis, theorem proving and reasoning-with-verifiers, and is usually evaluated end-to-end. The
quantity we measure --- how much of the outcome the generator is responsible for, given the
verifier --- is rarely reported, because in most of those domains the ground truth of an individual
proposal is not observable. Synthetic causal discovery is unusual in that it is.

\section{Discussion}
\label{sec:conclusion}

We set out to find a role in the discovery loop that an LLM could fill, built the architecture our
companion study's diagnosis implies, and it performs well: $0.08$ F1 over a well-tuned classical
active baseline, $0.75$--$0.96$ over the same models unscaffolded, at a thousand tokens an episode.
The uncomfortable part is the control. Replace the model with uniform noise and the number does not
move; vary proposal accuracy by a factor of four across five models and the number moves by
$0.026$, in no particular order. What produced the result is the machinery around the proposer ---
an exact belief update worth $0.29$, an information-gain criterion worth $0.06$, and a one-line
guard on the hypothesis budget worth $0.056$, more than the spread across every model we tried.

The methodological point generalizes beyond this task. Propose-and-verify architectures are
advocated because a good verifier makes an unreliable generator safe. That is true, and our guard
ablation quantifies it: a wrong proposal costs $0.056$ F1 with the guard in place and considerably
more without it. But the same property makes such architectures \emph{insensitive} to generator
quality, which means an end-to-end improvement over a no-LLM baseline is weak evidence that the LLM
contributed anything. The cheap control --- swap the model for a random generator, keep the
verifier --- is the one that settles it, and it is not standard practice.

The finding is conditional, and we would rather state the conditions than the headline. The
proposer does beat the control when the statistical estimator it corrects is underpowered
\emph{and} the variables carry real names: $+0.080$ F1 for \texttt{gemini-3-flash} on named
published structures at $n_{\mathrm{obs}}{=}60$. That is a real effect with a plausible mechanism
--- domain knowledge is information the data does not contain --- and it is the regime real
scientific applications live in. The gap left to close is large: perfect edits take this system to
$0.999$ F1, meaning every error that remains is a missing or spurious adjacency, and the best model
we measured claims under half of it.

Limitations are in Appendix~\ref{app:limitations}. The main ones: the exact posterior that makes
the verifier trustworthy is affordable only to about $d = 12$; all results assume linear-Gaussian
mechanisms, causal sufficiency and hard interventions; and our random-editor control is matched to
the LLM's edit \emph{rate}, which is a fair but not the only possible calibration.

\section{Formal background}
\label{app:background}

\paragraph{Model class.}
A linear-Gaussian structural causal model over a DAG $G$ on $d$ nodes sets
$X_j = \sum_{i \in \mathrm{pa}_G(j)} \beta_{ij} X_i + \varepsilon_j$ with
$\varepsilon_j \sim \mathcal{N}(0, \sigma_j^2)$ independent. We assume causal sufficiency,
faithfulness and full observability.

\paragraph{Equivalence.}
Two DAGs are Markov equivalent iff they share a skeleton and a set of unshielded colliders
($i \to k \leftarrow j$ with $i,j$ non-adjacent). The class is represented by a CPDAG: edges
compelled in every member are directed, the rest undirected. Observational data identify $G$ only
up to its CPDAG.

\paragraph{Interventions.}
A hard intervention $\mathrm{do}(X_a = v)$ replaces $a$'s structural equation by a constant,
deleting edges into $a$. Under our assumptions the interventional distribution of an adjacent $X_b$
shifts iff $a \to b$, which is what makes an experiment informative about orientation.

\paragraph{Scoring and design.}
For a candidate $h$ we fit by least squares and use $\mathrm{BIC}_h = -2\ell_h + k_h \log n$,
treating $w_h \propto \exp(-\tfrac12 \mathrm{BIC}_h)$ as a posterior under a uniform structure
prior. Writing $H$ for the true hypothesis index and $Y_a$ for the batch from
$\mathrm{do}(X_a = v)$, we choose
$a_t = \arg\max_a \mathbb{H}[H] - \mathbb{E}_{Y_a}\mathbb{H}[H \mid Y_a]$, estimating the
expectation from $12$ sampled outcomes. Both entropies are over the finite candidate set.

\paragraph{Metrics.}
\emph{Directed-edge F1} scores submitted arrows: an arrow counts only if adjacency and orientation
are both right. \emph{Skeleton F1} ignores direction and upper-bounds it. \emph{SHD} counts
single-edge edits needed to reach $G$.

\section{Instances, models and the difficulty ladder}
\label{app:instances}

Instances are sampled and filtered by a fixed acceptance policy, identical for every arm. A
candidate is rejected if its CPDAG leaves fewer than two undirected edges, if every undirected edge
meets the same node, if the skeleton is disconnected, if no intervention is needed, or if any
relevant structural partial correlation falls below a faithfulness margin of $0.1$. Edge weights
are drawn from $(-2,-0.5) \cup (0.5,2)$ with unit noise variance.

The five proposers are \texttt{qwen/qwen3-coder-30b-a3b-instruct},
\texttt{openai/gpt-4o-mini-2024-07-18}, \texttt{openai/gpt-5.4-mini},

OpenRouter at temperature zero.

density ($|E| \approx 1.4d$) PC's skeleton is wrong so often that every arm is capped at the same
low ceiling and no experiment helps --- a limitation of the instance design worth naming.

\section{Prompts}
\label{app:prompts}

\paragraph{Proposer (system).}
\begin{quote}\small\ttfamily
You audit the adjacency structure of a causal graph estimated from a small sample. The world is an
unknown linear-Gaussian DAG with no hidden confounders and full observability. You are given the
correlation matrix, the partial correlation of every pair given all other variables, and the
adjacency set the PC algorithm returned from the same sample. Read the statistics like this: for a
linear-Gaussian DAG, two variables are directly connected if and only if their partial correlation
given all others is non-zero. So a pair with a sizeable partial correlation that PC left
non-adjacent is a likely FALSE NEGATIVE, and a pair PC made adjacent whose partial correlation is
near zero is a likely FALSE POSITIVE. With a small sample PC's independence tests are underpowered,
so borderline values matter. List only the pairs you would genuinely bet on --- an empty list is a
valid and often correct answer. Do not restate the whole graph; report edits only. At most 4
removals and 4 additions. Call propose\_skeleton\_edits exactly once.
\end{quote}

In the named condition one sentence is appended: \texttt{The variables are named, and the names are
meaningful: they come from \{domain\}. Use what you know about this domain alongside the statistics
--- a pair that is implausible on domain grounds is a good removal candidate even when the
statistics are borderline, and vice versa.}

\paragraph{Proposer (user).} A JSON object with the variable list, the observational summary (row
count, means, standard deviations, correlation matrix, full-order partial correlation matrix), PC's
adjacency list, and the currently non-adjacent pairs.

\paragraph{Sanitizer.} Every model-produced structure passes through one shared routine before it
touches the pipeline: indices are coerced and range-checked, self-loops and duplicates dropped,
removals kept only if the pair is currently adjacent and additions only if it is not, and any edge
that would create a cycle discarded. Malformed tool calls are re-prompted at most twice. The audit
in Section~\ref{sec:credit} scores edits \emph{after} sanitization, so it measures what the system
acted on.

\section{What each proposer actually proposes}
\label{app:edits}

Aggregate precision hides the shape of the behaviour. Figure~\ref{fig:a1} and
Table~\ref{tab:decomp} break each proposer's edits into removals and additions and score each kind
against its own chance rate, since a removal is drawn from PC's adjacency set and an addition from
its complement --- two very different base rates.

The pattern is consistent and, we think, the single most interpretable result about proposal
quality in this paper: \textbf{the better proposers propose less}. \texttt{gpt-4o-mini} makes
$6.4$ edits per instance and is right $7.9\%$ of the time; \texttt{gemini-3-flash} makes $3.0$ and
is right $32.8\%$ of the time. The relationship across the five models is monotone
(Figure~\ref{fig:a1}(c)). Most of the difference is restraint about \emph{removals}: PC invents
only about $0.1$ spurious adjacency per instance, so almost every removal is a mistake, and the
weak models propose $3.3$--$3.7$ of them while \texttt{gemini-3-flash} proposes $0.4$. On the
additions, where there really are about $1.75$ missing edges to find, every model is above chance
and the spread is smaller ($1.6\times$ to $3.9\times$).

\section{Additional results}
\label{app:extra}

\paragraph{Two ablations that do nothing.}
Adding PC's equivalence class to the edit-derived candidate set changes no episode in any run. This
is an identity rather than a null result: every member of PC's equivalence class is an acyclic
orientation of PC's skeleton, and the guard already reserves half the budget for the best-scoring
such orientations. Likewise, submitting posterior edge marginals instead of the MAP graph reproduces
the MAP graph, because the posterior concentrates hard (mean MAP weight $0.96$, final entropy
$0.14$ nats). We report both because they bound how much of the design is load-bearing: neither is.

\paragraph{An enumeration detail we corrected.}
Our first implementation listed all proposed removals before any addition and capped the variant
list at six, so a model that proposed four removals lost most of its additions --- and additions are
where a proposer's signal is, since PC misses far more edges than it invents. We reordered the list
(all-edits variant first, then single edits interleaved) and raised the cap, then replayed every
affected arm on the \emph{recorded} proposals, so the comparison is paired on identical model
output. It changed nothing: all five models moved by at most $0.007$ F1, none significantly. We
report it because it was the most plausible mechanical explanation for the flat capability curve in
Section~\ref{sec:credit}, and it is not the explanation.

\section{Limitations}
\label{app:limitations}

\paragraph{The control is matched on rate, not on distribution.}
\texttt{random-edits} proposes the same \emph{number} of removals and additions the models are
allowed, drawn uniformly. A control matched instead to each model's own edit-count distribution, or
one biased toward high-partial-correlation pairs, would be a stronger test. We chose the uniform
version because it is the weakest possible proposer, which makes ``the LLM does not beat it'' the
more surprising direction.

\paragraph{The proposer is mostly asked to do statistics.}
On anonymized variables the model can use only the correlation and partial-correlation matrices,
and reading a partial correlation against its sampling noise is close to the competency our
companion study showed these models lack. Section~\ref{sec:when} is the corrective, but it covers
five small published structures, not a broad domain sample.

\paragraph{Exactness does not scale.}
The filtering that makes proposals safe depends on an exact posterior over an enumerated candidate
set, affordable to about $d = 12$. Beyond that the set must be sampled, and a sampled filter can
miss the truth even when a proposal contains it. Whether the conclusions survive that substitution
is untested.

\paragraph{One model class, one front-end.}
All results assume linear-Gaussian mechanisms, causal sufficiency and hard interventions, with PC
as the estimator. We vary how wrong the estimator is through sample size and through PC's
significance threshold; a different estimator may leave a differently-shaped residue for a proposer
to attack.
