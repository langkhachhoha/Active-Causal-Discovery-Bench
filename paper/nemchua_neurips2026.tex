\begin{abstract}
Scientific agents increasingly pair a generative proposer with a mechanical verifier, but a verifier
good enough to rescue weak proposals also makes end-to-end accuracy a poor measure of what the
proposer contributed. We audit that attribution problem in active causal discovery through \nem{},
which asks an LLM to flag likely errors in a PC-estimated skeleton and delegates every remaining
decision to a bounded model-based pipeline. \nem{} reaches $0.954$ directed-edge F1 against $0.874$
for PC+greedy+Meek on $80$ paired instances. Three controls locate that gain. A random editor
matched to each model's \emph{realized} edit counts, run $200$ times per instance, places every
model above its own null (percentile $0.53$--$0.59$): proposal content does carry information, and
the cap-matched control we first reported understated it. But a two-line ranker that executes the
rule we gave the proposer, with no world knowledge, beats every model by $0.021$--$0.028$ F1 and
puts the truth in the candidate set $88\%$ of the time against the LLM's $68\%$. Auditing the
proposals explains why capability does not help: our prompt asserted that a nonzero partial
correlation given all other variables implies adjacency, which is false for a DAG, and the models'
wrong additions concentrate on exactly the co-parent pairs that error invites --- more so the more
capable the model ($\rho=0.90$). Stating the rule correctly removes the artifact without recovering
accuracy, because the false rule exposed the moral graph, which the front-end discards. Both the
proposer and the interface it is given must be controlled.
\end{abstract}

\section{Introduction}
\label{sec:intro}

Propose-and-verify has become a natural architecture for LLM scientific agents: the model generates
candidate hypotheses, trusted machinery evaluates them, and only candidates that survive this
evaluation influence the answer. This division of labor is appealing because a strong verifier can
bound the damage caused by an unreliable generator, but the same protection complicates scientific
attribution. An end-to-end comparison against a baseline that contains neither component
cannot reveal whether the model supplied useful hypotheses, whether the verifier supplied a better
decision rule, or whether the interaction between them mattered.

Resolving that ambiguity requires counterfactuals that are usually absent from evaluations of
scientific agents. Three of them turn out to matter, and each changed our conclusion. The first is a
random proposer matched to what the model actually proposes rather than to what it is allowed to
propose; matched to the cap, it looked as good as the LLM, and matched to realized behaviour it does
not. The second is a proposer with no world knowledge that mechanically executes the instruction the
LLM was given; it beats every model we tested. The third is an audit of the instruction itself,
which in our case asserted a criterion that is false for a DAG --- and which the strongest models
followed most faithfully. Together these say something a single end-to-end number cannot: the
proposal channel carries real signal, the language model captures only part of it, and a large part
of what looks like model behaviour is the shape of the interface we built.

Active causal discovery provides an unusually transparent setting for this audit because its central
ambiguity has an experimental resolution. Observational data may leave $A \to B$ indistinguishable
from $B \to A$, whereas a carefully chosen intervention can resolve the direction. An agent receives
an observational sample, a small experimental budget, and
the task of returning the directed graph. At the graph sizes studied here, candidate generation and
model-based updating remain inspectable graph by graph, allowing us to observe not only what the LLM
proposed but also whether that proposal entered the candidate set, survived scoring, and altered the
submitted graph. The main benchmark names variables $X_0 \dots X_{d-1}$ to remove semantic cues,
while a separate condition restores published labels and a domain description to probe the distinct
setting in which prior knowledge might supplement limited data.

The resulting evaluation treats system quality and proposer value as related but separate questions.
A protective decision layer may transform weak proposals into strong final answers while
simultaneously erasing differences among generators. We therefore follow each proposal from its
edit-level correctness, through candidate-set coverage and ranking, to its effect on the submitted
graph. This view asks not only whether the assembled system works, but whether its behavior would
have changed had the language model contributed less informative proposals.

\paragraph{How this differs from adjacent work.}
Three literatures are close and none asks our question. \emph{LLMs for causal discovery} measures
whether a model can name causal relations directly, so the proposal is the output and attribution is
not at issue. \emph{Active intervention design} optimizes which experiment to run given a hypothesis
space, treating that space as given rather than model-supplied. \emph{Evaluations of
propose-and-verify systems} report end-to-end accuracy against baselines lacking the whole
architecture --- exactly the comparison that cannot separate generator from verifier. We sit at the
intersection, and ask how much of the final accuracy the model is responsible for
(Appendix~\ref{sec:related}).

\paragraph{Contributions.}
\begin{itemize}\itemsep1pt
\item \textbf{An auditable proposal interface.} We isolate the LLM to skeleton edits and make the
remaining candidate search, scoring, experiment selection, and likelihood update mechanical. This
turns the path from proposal to final graph into a sequence of measurable bottlenecks
(Section~\ref{sec:method}).
\item \textbf{Controls that reassign the credit.} Inside one fixed downstream architecture we
compare no edits, random edits matched to realized proposal volume over $200$ draws per instance,
LLM edits, a data-only ranker, and oracle edits. The LLM beats its own matched null but loses to
the ranker by more than it wins by, and decision-layer ablations dominate both
(Sections~\ref{sec:headline}--\ref{sec:credit}).
\item \textbf{An interface-level explanation for the flat capability curve.} Auditing every
proposed edit against the true graph shows that models' errors concentrate on the co-parent pairs
our misspecified adjacency rule endorses, increasingly so with capability ($\rho=0.90$). Correcting
the rule removes the artifact but not the deficit, for a reason worth stating: the false rule
exposed the moral graph, which the front-end discards (Section~\ref{sec:mechanism}).
\item \textbf{A scoped account of when proposal content may matter.} Sample-size sweeps and an
exploratory semantic condition identify data scarcity and meaningful prompt context as plausible
boundary conditions. We also state the statistical and control-design limitations that prevent
these observations from supporting a broader claim about LLM causal knowledge
(Section~\ref{sec:when}).
\end{itemize}

\section{Background: from observation to intervention}
\label{sec:background}

We summarize only the concepts needed to interpret the experiments here and give the formal model
in Appendix~\ref{app:background}. Suppose $d$ observed variables are generated by an unknown
directed acyclic graph (DAG), with each variable a noisy linear function of its parents.
Observational data can reveal which pairs are directly connected, forming the graph's
\emph{skeleton}, and can orient some but not all of those connections; the observationally
indistinguishable DAGs constitute a Markov equivalence class. Interventions supply the missing
asymmetry: forcing $X_a$ to an unusual value can change its descendants, and among the variables
adjacent to $a$, only its children respond. A sequence of such local comparisons can therefore
resolve directions that observation alone leaves ambiguous.

An active discovery system must decide both which graphs remain plausible and which interventions
will best distinguish among them. Its candidate set $\Hyp$ imposes a hard epistemic ceiling, since
no experimental policy can recover the true graph after that graph has been excluded. We construct
the initial skeleton with PC, which removes an adjacency when the data support a conditional
independence. Finite-sample tests can miss genuine dependencies, so the resulting estimate is strong
but incomplete: PC attains skeleton F1 $0.947$ on our main instances, while its estimated equivalence
class contains the true DAG only $45\%$ of the time. This combination creates a meaningful proposal
task. There is enough statistical structure to anchor the search, but also enough residual error for
a proposer to expand the set of graphs that the decision layer can consider.

\section{Method}
\label{sec:method}

\nem{} separates proposal from decision authority across the stages in Figure~\ref{fig:method}. The
language model acts only once, before any intervention is collected, and can alter the search only by
naming suspected skeleton errors. Candidate construction, graph scoring, experiment selection,
evidence accumulation, and final submission then proceed without further model input. This boundary
makes a proposal consequential only through the hypotheses that it adds to or displaces from the
finite candidate set.

\paragraph{1. Propose a local correction.}
The model receives the correlation matrix, the partial correlation of every pair given all other
variables, PC's adjacency set, and the currently non-adjacent pairs. Its single tool call may remove
or add at most four adjacencies of each kind, after which the model leaves the loop and never observes
interventional data. This interface deliberately asks for a local correction rather than a complete
graph, but the statistical guidance in the executed prompt is flawed: it describes non-zero
full-order partial correlation as equivalent to direct adjacency. Conditioning on a collider such as
$X_1 \to X_3 \leftarrow X_2$ can instead make $X_1$ and $X_2$ dependent even though they are not
adjacent. Because Appendix~\ref{app:prompts} reproduces and audits the executed prompt, the proposer
results can be interpreted accurately as evidence about this statistically misspecified
interface, not as a general test of whether LLMs can propose causal structure from valid evidence.

\paragraph{2. Expand the neighborhood without discarding the anchor.}
Let $S$ denote PC's skeleton. We construct its all-edits variant and every single-edit variant, then
enumerate acyclic orientations exhaustively when the space is small and by sampling otherwise.
Least-squares fits and linear-Gaussian BIC scores on the observational sample define
$w_h \propto \exp(-\tfrac12\mathrm{BIC}_h)$ over a retained set $\Hyp$ of at most $48$ DAGs. These
normalized scores form an approximate belief over a truncated hypothesis set rather than an exact
structure posterior, so proposal and pruning determine what the later evidence can possibly recover.

To prevent edited variants from consuming the entire candidate budget, the guard first reserves
half of $\Hyp$ for the best-scoring orientations of the unedited skeleton. Edited orientations fill
the remaining slots, with unused capacity backfilled from the original skeleton. This reservation
reduces displacement without eliminating it: an unedited-only arm may use all $48$ slots for the
base skeleton, whereas a guarded edit arm guarantees only half of them. The protection offered by
the guard is therefore an empirical property of this budget and search procedure, not a formal
guarantee that accepting a proposal is cost-free (Section~\ref{sec:mechanism}).

\paragraph{3. Choose experiments, update the weights, and submit.}
For each variable whose orientation remains ambiguous under $w$, we estimate the expected
information gain about the hypothesis index from $12$ Monte Carlo outcomes and intervene on the
maximizer. Although the objective is the standard Bayesian design criterion, its computed value is
an approximation under fitted parameters and a finite candidate set. Each observed interventional
batch is then evaluated under the candidates' mutilated linear-Gaussian likelihoods, which are
available in closed form conditional on those fitted parameters. The weights are multiplied and
renormalized after every experiment, and the loop continues until the budget is exhausted or
$\max_h w_h > 0.999$, at which point the highest-weight retained graph is submitted.

\section{Experimental setup}
\label{sec:setup}

\paragraph{Instances.}
The main benchmark contains twenty accepted instances at each of four graph sizes,
$d \in \{4,6,8,10\}$ with $|E|=d$, yielding $80$ instances shared across all arms. Acceptance
requires a connected skeleton and a nontrivial, distributed orientation problem: the equivalence
class must contain at least two undirected edges, those edges cannot all meet at one node, and at
least one intervention must be necessary. Edge coefficients are drawn from
$(-2,-0.5)\cup(0.5,2)$, bounded away from zero so that faithfulness violations are not generic.
Unless otherwise noted,
each instance supplies $n_{\mathrm{obs}}=300$ observational
rows and $n_{\mathrm{int}}=150$ samples per intervention. The experimental budget is
$|I^*|+1$ for a minimum identifying set $I^*$, allowing $2.7$ interventions on average, and a random
permutation maps the variables to anonymous labels $X_0 \dots X_{d-1}$; Appendix~\ref{app:instances}
reports the complete difficulty ladder and its acceptance statistics.

\paragraph{Comparators and controls.}
Every arm runs on every instance, making the principal comparisons paired. Reference arms include
an oracle ceiling; \texttt{PC+greedy}, which intervenes on the highest-degree ambiguous node and
orients by a mean-shift test, with or without Meek closure; and \texttt{LLM-e2e}, which gives the
same models raw data and control of the full loop. The proposal-content controls retain \nem's
decision layer while changing only the source of its search neighborhood. The \texttt{no-edits}
arm uses PC's original skeleton, \texttt{random-edits} samples up to four removals from PC
adjacencies and four additions from currently non-adjacent pairs, and \texttt{perfect-edits} applies
up to four ground-truth errors of each kind. The cap-matched random arm is a weak shared control
rather than a per-model null, so Section~\ref{sec:credit} adds a per-model one: the same editor
constrained to each proposal's realized counts, drawn $200$ times per instance. Two further arms
carry no model at all. \texttt{stat-edits} ranks PC's adjacencies by how weak their full-order
partial correlation is and the non-adjacent pairs by how strong theirs is, taking the top of each
list --- the instruction we give the proposer, executed mechanically. \texttt{true-skeleton} hands
over the true adjacency set at any edit distance, separating an edit budget that is too small from
an orientation problem no adjacency information can solve. A final pair of arms reruns the proposer
under a corrected statistical interface (Section~\ref{sec:mechanism}). Additional arms supply PC's
equivalence class, complete DAGs written by the LLM, or random DAGs. Decision-layer ablations replay
the recorded LLM proposal and generally preserve candidate membership; the \texttt{no-guard}
ablation is the exception because its purpose is to let edited candidates compete for every slot.

\paragraph{Models, pairing, and proposal audit.}
We evaluate five proposers spanning roughly two orders of magnitude in price:
\texttt{qwen3-coder-30b}, \texttt{gpt-4o-mini}, \texttt{gpt-5.4-mini},
\texttt{claude-haiku-4.5}, and \texttt{gemini-3-flash}, all at temperature zero with forced tool
calls; Appendix~\ref{app:instances} lists the complete identifiers. The capability sweep runs on its
own cohort rather than on the main table's instances: $60$ instances at $d\in\{6,8,10\}$ with
$n_{\mathrm{obs}}{=}60$, chosen because the proposal channel is live only where the statistical
front-end is underpowered. Every table below states the cohort it uses, and numbers are comparable
across tables only within a cohort. Within an instance, every
mechanical ablation replays the same recorded proposal, preventing provider variability from
entering those contrasts. Error bars are $95\%$ confidence intervals over instances for arm means
and over paired differences for contrasts, while pairwise claims on the synthetic ladder use
two-sided Wilcoxon signed-rank tests with win and loss counts. The semantic study reuses each base
parameterization across five models, so pooled episode-level comparisons are descriptive rather than
independent confirmatory tests. To connect proposal behavior to downstream performance, we also
score every retained edit against the true skeleton: a removal is correct when PC introduced a
spurious adjacency, and an addition is correct when PC omitted a genuine one, so every reference to
``edits correct'' uses the post-sanitization changes that the pipeline actually receives.

\section{Results}
\label{sec:results}

\subsection{A strong system, and where its accuracy comes from}
\label{sec:headline}

Table~\ref{tab:main} reports every arm on the same $80$ instances. \nem{} reaches $0.954$ directed-edge
F1, against $0.874$ for \texttt{PC+greedy+Meek}, the strongest external baseline we include. Read on
its own, that gap is the kind of number a propose-and-verify paper reports as evidence that the
proposer works. The rest of this section takes it apart.

The first thing to establish is that most of the system's accuracy is not attributable to the
proposer at all. Removing the interventional likelihood update costs $0.285$ F1; replacing expected
information gain with random targeting costs $0.062$; removing the candidate-budget guard costs
$0.051$; removing the BIC weights costs $0.021$ (all $p<10^{-4}$, Figure~\ref{fig:credit}c). These
are one-at-a-time sensitivities rather than an additive decomposition --- the components interact,
and removing the update also makes every subsequent experiment uninformative --- so they do not sum
to the total. What they establish is a ranking: the decision layer is worth far more than anything
the proposal layer does, and a difference between proposers has to be read against that scale.

\paragraph{The guard, and why a wrong proposal is nearly free.}
Half the hypothesis budget is reserved for orientations of PC's unedited skeleton. That reservation
is worth $+0.051$ to the LLM arm and $+0.056$ to the random-edit arm, and \emph{exactly zero} to a
perfect proposer ($p=1.0$), which is the signature of a safety net: it pays only when the proposal
is wrong. Without it, truth-in-hypothesis-set falls from $0.68$ to $0.23$ and accuracy falls to
$0.903$, level with proposing nothing at all. A system built this way is deliberately insensitive to
its generator, which is exactly what makes end-to-end accuracy uninformative about the generator.

\subsection{Proposal content matters --- and a two-line ranker exploits it better}
\label{sec:credit}

\paragraph{A control matched to what each model actually proposes.}
Our first draft compared \nem{} against a random editor drawing the maximum four removals and four
additions. That control is matched to the \emph{cap}, not to behaviour: models differ by more than
a factor of two in how much they propose (Appendix~\ref{app:edits}), and the models that propose
least were being compared against a control proposing most. We therefore rebuilt the control per
instance and per model at each proposal's realized counts after sanitization, and ran it $200$ times,
so that every LLM proposal is placed inside the null distribution generated by its own volume.

The conclusion changes. At matched counts the null falls from $0.951$ to $0.939$ on the main cohort,
and the LLM sits at percentile $0.532$ of its own null ($+0.014$ F1, $103$ wins / $27$ losses / $30$
ties, $p<10^{-4}$). The effect is larger where data are scarce: percentile $0.591$ at
$n_{\mathrm{obs}}{=}60$ ($+0.030$) and $0.562$ at $n_{\mathrm{obs}}{=}300$ ($+0.017$), both
$p<10^{-4}$, and every one of the five models beats its own null in both regimes
(Figure~\ref{fig:credit}a). Proposal \emph{content} is therefore worth something beyond proposal
volume. The cap-matched control we reported first understated this, and we report the correction
rather than the original claim.

\paragraph{But the rule we gave the model is worth more than the model.}
The size of that effect is the point. We added a proposer with no world knowledge at all: rank PC's
adjacencies by how weak their full-order partial correlation is, rank the non-adjacent pairs by how
strong theirs is, take the top of each list. This is the instruction in our own prompt, executed
mechanically in two lines of code.

It beats every language model in every cohort where the exact posterior can be enumerated: $0.976$
against $0.954$ on the main cohort ($-0.021$ for the LLM, $p=0.003$), $0.861$ against $0.832$ at
$n_{\mathrm{obs}}{=}60$ ($p<10^{-3}$), and $0.967$ against $0.939$ at $n_{\mathrm{obs}}{=}300$
($p<10^{-4}$). It is not a marginal difference in the same direction as the models: it is larger
than the LLM's own margin over the matched-random control, and it runs the other way. The mechanism
is visible upstream --- the ranker puts the true DAG in the hypothesis set on $87.5\%$ of instances
against the LLM's $68.1\%$, and lifts the best available F1 in the set from $0.967$ to $0.985$.

Figure~\ref{fig:when}a shows the two proposers against sample size. The LLM's advantage over
proposing nothing decays from $+0.044$ at $n_{\mathrm{obs}}{=}40$ to $-0.003$ at $1000$, the
crossover our first draft reported. The ranker's does not decay: it holds $+0.043$ at
$n_{\mathrm{obs}}{=}1000$. The proposal channel stays open at every sample size we tested. What
changes with sample size is whether the model uses it.

\paragraph{Capability does not close the gap.}
Across five proposers spanning roughly two orders of magnitude in price, edit precision varies by a
factor of $4.2$ ($0.079$ to $0.328$) while final F1 varies by $0.026$, and the ordering is not
preserved ($\rho=0.30$, n.s., Figure~\ref{fig:credit}b). Every model in that sweep falls below the
ranker. Whatever separates a weak proposer from a strong one is not what this task rewards.

\subsection{The interface, not the model, is the binding constraint}
\label{sec:mechanism}

A flat capability curve invites the obvious objection: perhaps we simply asked badly. We did, and
the way in which we asked badly is measurable.

\paragraph{We stated a false adjacency criterion.}
The executed prompt told the proposer that for a linear-Gaussian DAG, two variables are directly
connected if and only if their partial correlation given all others is nonzero. That is the
criterion for a Gaussian \emph{graphical model}, not a DAG. The precision matrix of a linear-Gaussian
DAG is supported on the \emph{moral} graph, so any two parents of a common child remain partially
correlated given everything else while being non-adjacent. Our instruction therefore actively
directs a proposer to add exactly those co-parent pairs.

The models complied. Classifying every wrong addition by whether the pair are co-parents in the true
DAG, the concentration on co-parents rises monotonically with edit precision across the five models
--- $1.1\times$ chance for \texttt{qwen3-30b} up to $6.0\times$ for \texttt{gemini-3-flash}, Spearman
$\rho=0.90$ ($p=0.037$, Figure~\ref{fig:mechanism}a). For \texttt{gemini-3-flash}, $75\%$ of wrong
additions are co-parent pairs, and $83\%$ of all its additions are either true edges or that one
artifact. The better the model, the more faithfully it executed a misspecified instruction. That is
what the flat capability curve is made of: capability was being spent on compliance.

\paragraph{Correcting it removes the artifact, not the deficit.}
We reran both prompts on the same instances with the same five models, differing only in the
statistics supplied and the rule stated. The corrected interface gives PC's own separating sets with
their partial correlations and $p$-values, and states the adjacency criterion properly.

It works as diagnosis: co-parent enrichment collapses to chance for every capable model
($6.1\times \to 1.4\times$ for \texttt{gemini-3-flash}, $3.7\times \to 1.4\times$ for
\texttt{haiku-4.5}, Figure~\ref{fig:mechanism}b). It does not work as a fix. Pooled over five models
the corrected prompt is worth $-0.009$ F1 (n.s.), and it \emph{costs} the two models that had been
following the false rule most closely: $-0.051$ for \texttt{haiku-4.5} ($p=0.003$) and $-0.025$ for
\texttt{gemini-3-flash} (n.s.). Under the corrected interface the LLM no longer beats its own
count-matched null at all (percentile $0.515$, $p=0.34$).

The reason is that the two interfaces expose different information. The full-order partial
correlation is wrong about adjacency but describes the moral graph, an object PC never computes and
whose extra edges are informative about missing ones; \texttt{gemini-3-flash} recovers $58$ correct
edits under it against $16$ under the corrected prompt. Separating sets, by contrast, are precisely
what PC already used to build the skeleton, so asking a model to second-guess them is asking it to
redo a computation on evidence that has been extracted. Our misspecification was real, and fixing it
made proposals worse. We report this because it is the opposite of what we expected, and because it
bounds the objection: the negative result is not an artifact of the wrong prompt.

\subsection{When a proposer is worth anything}
\label{sec:when}

Two conditions have to hold together. Data must be scarce enough that the statistical front-end is
underpowered --- at $n_{\mathrm{obs}}{=}1000$ the LLM's contribution is indistinguishable from zero
(Figure~\ref{fig:when}a). And the variables must carry meaning. On five published network structures
with their real variable names restored, naming is worth $+0.021$ F1 at $n_{\mathrm{obs}}{=}60$
($p=0.008$) and $+0.003$ at $n_{\mathrm{obs}}{=}300$ (n.s., Figure~\ref{fig:when}b). This is our one
result in which an LLM does something no statistic can, and we hold it loosely: the structures are
published, so transferable knowledge and memorization are not separable here, and names and domain
description vary together.

Even there the comparison is unflattering. Pooled over the five structures, the named-variable LLM
remains $0.016$ F1 below the ranker that sees no names at all ($p=0.064$), significantly below it on
\texttt{sachs} ($-0.039$, $p=0.001$) and \texttt{survey} ($-0.059$, $p=0.025$). The one structure
where names are directionally worth more than statistics is \texttt{earthquake} ($+0.033$,
$p=0.09$), and the pattern across structures --- help on \texttt{earthquake} and \texttt{cancer},
none on \texttt{sachs} --- suggests what transfers is everyday causal common sense rather than
domain expertise (Appendix~\ref{app:semantic}).

\paragraph{What is left on the table.}
Perfect edits reach $0.999$ on the main cohort, $+0.097$ over proposing nothing, and the true
adjacency set at any edit distance scores identically ($p=1.0$), so the four-edit budget never binds
on synthetic instances. On the published structures it binds hard: $0.962$ against $0.890$ at
$n_{\mathrm{obs}}{=}60$ (Appendix~\ref{app:ceiling}). Either way the channel is largely unclaimed.

\section{Conclusion}
\label{sec:conclusion}

\nem{} works as an active causal discovery system, and the audit changes what that is worth knowing
for. Proposal content does carry information: matched against random editors of exactly its own
size, every model we tested lands above its own null. But the amount is small, it does not track
model capability, and a proposer with no world knowledge --- one that mechanically executes the rule
we wrote into the prompt --- extracts more of it than any language model, by a margin larger than
the models' own margin over random. Most of the system's accuracy comes from elsewhere entirely:
from the interventional likelihood update, and from a guard that is worth $+0.05$ when the proposal
is wrong and exactly nothing when it is right.

The most useful thing we found was not about the models. Auditing every edit against the true graph
showed that our own prompt asserted a criterion that is false for a DAG, that the strongest models
followed it most faithfully, and that their characteristic errors are the ones it endorses. Stating
the rule correctly removed the artifact and made proposals worse, because the false statement had
been exposing the moral graph --- an object the constraint-based front-end never computes --- while
the correct one asks a model to re-derive what the front-end already used. What a proposer can
contribute is not fixed by the data; it is fixed by what the rest of the pipeline has already
consumed, and an interface can be statistically wrong and still informative.

A propose-and-verify result therefore needs two controls rather than one. A random proposer matched
to realized behaviour, not to the budget cap, bounds what proposal volume buys; a mechanical
proposer executing the stated instruction bounds what the instruction buys. Only what survives both
belongs to the model. Here that residue is real and small, and the honest headline is not that the
LLM failed but that we never gave it a question its capability could answer.

\section{Formal background}
\label{app:background}

\paragraph{Causal model and identifiability.}
A linear-Gaussian structural causal model over a DAG $G$ on $d$ nodes sets
$X_j = \sum_{i \in \mathrm{pa}_G(j)} \beta_{ij}X_i + \varepsilon_j$, with independent noise
$\varepsilon_j \sim \mathcal{N}(0,\sigma_j^2)$ under assumptions of causal sufficiency,
faithfulness, and full observability. Two DAGs are Markov equivalent exactly when they share a
skeleton and the same
unshielded colliders, where $i \to k \leftarrow j$ and $i,j$ are non-adjacent. A CPDAG represents
this class by directing edges compelled in every member and leaving the remaining orientations
undetermined, so observational data identify $G$ only up to that equivalence class. A hard
intervention $\mathrm{do}(X_a=v)$ replaces the structural equation for $a$ with a constant and
deletes edges entering $a$. For a variable $X_b$ adjacent to $a$, the mean of $X_b$ under the
intervention differs from its observational mean when $a \to b$ and $v$ differs from
$\mathbb{E}[X_a]$, and is unchanged when $b \to a$; with coefficients bounded away from zero this
holds for every adjacency, which is the local evidence used to resolve orientation. Non-adjacent
descendants of $a$ also shift, so the signal is not confined to children --- what is specific to
children is that the shift is not mediated by another intervened-on path.

\paragraph{Scoring, experimental design, and evaluation.}
For each candidate $h$, we fit parameters by least squares and compute
$\mathrm{BIC}_h=-2\ell_h+k_h\log n$, normalizing
$w_h \propto \exp(-\tfrac12\mathrm{BIC}_h)$ into approximate model weights. Because BIC only
approximates integrated evidence, these weights are not an exact posterior under a fully specified
structure prior. Writing $H$ for the hypothesis index and $Y_a$ for the batch obtained from
$\mathrm{do}(X_a=v)$, the selected intervention is
$a_t=\arg\max_a \mathbb{H}[H]-\mathbb{E}_{Y_a}\mathbb{H}[H\mid Y_a]$, with the expectation
estimated from $12$ outcomes sampled under the fitted candidate models, with both entropy terms
defined only over the truncated finite set. We evaluate the submitted graph with directed-edge F1, which
requires both adjacency and orientation to be correct, skeleton F1, which ignores direction, and
structural Hamming distance (SHD), which counts the single-edge edits needed to recover $G$.

\section{Related work}
\label{sec:related}

Active causal discovery has approached intervention selection through coverage of a Markov
equivalence class, information-theoretic acquisition, Bayesian experimental design over candidate
structures, and learned or amortized policies. \nem's decision layer belongs to the model-based
branch of this literature and is not proposed as a new causal discovery algorithm. We use it because
its finite candidate set, explicit weights, and recorded updates expose the fate of each proposed
structural change, providing an unusually inspectable substrate for attribution.

Language models enter causal discovery at several levels of authority, ranging from local semantic
judgments to control of an experimental loop. They have been used as semantic experts for pairwise
cause-effect judgments, as priors or initializers for structure learning, as search operators over
graphs, and as agents that control the entire experimental loop. Much of this work evaluates only the
final graph on variables with meaningful names, where world knowledge may supply information absent
from a statistical learner, and rarely includes a model-free proposer while holding the downstream
procedure fixed. Our results offer a possible reconciliation of the mixed empirical picture:
semantic information may help when the observational estimate is weak, yet differences among
proposers can become invisible once a strong front-end or protective downstream filter determines the
answer. The present semantic experiment is consistent with this account but cannot identify it.

The same attribution problem arises wherever a generator is evaluated only after a strong filter has
acted. Program synthesis, theorem proving, and reasoning-with-verifiers all generate candidates
cheaply and rely on trusted machinery to select among them, while success is usually measured at the
boundary of the assembled system. Estimating the generator's marginal contribution is difficult when
individual proposals have no observable ground truth. Synthetic causal discovery is unusual in
providing both edit-level labels and a final task score, which allows proposal quality to be separated
from the quality of the answers produced after filtering.

\section{The algorithm in full}
\label{app:algorithm}

This appendix answers, in one place, the questions a reader needs in order to reimplement \nem{}.

\paragraph{Candidate construction.}
\begin{enumerate}[leftmargin=1.4em,itemsep=1pt,topsep=2pt]
\item Run PC (Fisher-Z, $\alpha=0.05$) on the observational panel and coerce the result to a valid
CPDAG. If PC returns a cyclic directed part, every directed edge is demoted to undirected.
\item Obtain a proposal: a set of removals $R$ and additions $A$ over the undirected skeleton.
Removals not present in PC's adjacency set and additions already present are dropped; pairs are
canonicalized, de-duplicated, range-checked, and truncated to at most four of each.
\item Form skeleton variants: PC's skeleton unchanged; the skeleton with \emph{all} edits applied;
then one variant per individual edit. This ordering matters --- an earlier version listed all
removals before any additions and truncated the list, which silently discarded the additions of
verbose proposers (Appendix~\ref{app:ordering}). At most $10$ variants are kept.
\item For each variant, enumerate acyclic orientations, up to $1024$ per skeleton. Enumeration is
exhaustive below that bound and uniformly subsampled above it. Every candidate is scored by exact
linear-Gaussian BIC on the observational panel.
\item Prune to $M=48$ candidates. Half the budget is \emph{reserved} for the best-scoring
orientations of PC's unedited skeleton; the remainder is filled by BIC rank across all variants.
This is the guard. Candidates are de-duplicated by edge set before pruning, so an orientation
reachable from two variants occupies one slot.
\end{enumerate}

\paragraph{Weights and the active loop.}
Each candidate $h$ is fitted by least squares and weighted by $w_h \propto \exp(-\tfrac{1}{2}
\mathrm{BIC}_h)$. At each step the target maximizing expected information gain about the hypothesis
index is chosen; the intervention value is $v = \mu_a + 2\sigma_a$ under the current MAP candidate,
a fixed displacement large enough to separate children from parents at these sample sizes. The EIG
expectation uses $12$ Monte Carlo outcome \emph{batches}, each a full draw of $n_{\mathrm{int}}$
rows from the mutilated model of a candidate sampled from $w$, so the simulated evidence has the
same precision as the evidence the step will actually receive. A target may be selected more than
once; nothing forbids repetition, and with $12$ outcomes the selector occasionally does repeat.
After each experiment the weights are multiplied by the exact interventional likelihood under each
candidate's mutilated model and renormalized. The loop stops at the budget, or early when the MAP
candidate's weight exceeds $0.95$ and no undirected edge remains ambiguous --- an edge counts as
ambiguous when the posterior mass placed on its two orientations differs by less than $0.9$.

\paragraph{The random editor.}
Removals are drawn without replacement from PC's adjacency set and additions from the non-adjacent
pairs, uniformly. In the main table the counts are fixed at the cap, four of each; in the
permutation control of Section~\ref{sec:credit} they are set to the realized counts of the proposal
being tested, after the same sanitization the LLM arm applies.

\paragraph{Statistics.}
Confidence intervals on arm means are normal intervals over instances; intervals on contrasts are
percentile bootstrap over paired differences with $4000$ resamples. Paired tests are two-sided
Wilcoxon signed-rank on the nonzero differences, with exact ties excluded from the statistic and
reported separately in the win/loss/tie counts. Where an arm has several models on one instance,
the instance's value is the mean over models before pairing, so the unit of analysis is the
instance. We do not correct for multiple comparisons; the contrasts are pre-specified by the ladder
and reported in full, including the ones that are null.

\section{Instances, models and the difficulty ladder}
\label{app:instances}

Instances are sampled and filtered by a fixed acceptance policy, identical for every arm. A
candidate is rejected if its CPDAG leaves fewer than two undirected edges, if every undirected edge
meets the same node, if the skeleton is disconnected, if no intervention is needed, or if any
relevant structural partial correlation falls below a faithfulness margin of $0.1$. Edge weights
are drawn from $(-2,-0.5) \cup (0.5,2)$ with unit noise variance.

The five proposers are \texttt{qwen/qwen3-coder-30b-a3b-instruct},
\texttt{openai/gpt-4o-mini-2024-07-18}, \texttt{openai/gpt-5.4-mini},
\texttt{anthropic/claude-haiku-4.5} and \texttt{google/gemini-3-flash-preview}, all served through
OpenRouter at temperature zero. This range is intended to create meaningful variation in proposal
behavior rather than to support provider-level claims, since the models differ simultaneously in
scale, training data, and instruction tuning.

Density is $|E| = d$ by design, which calibrates PC to be competent but imperfect. At higher
density ($|E| \approx 1.4d$) PC's skeleton is wrong so often that every arm is capped at the same
low ceiling and no experiment helps. This is a limitation of the instance design rather than a
claim about dense causal discovery.

\section{Prompts}
\label{app:prompts}

\paragraph{Proposer (system).}
\begin{quote}\small\ttfamily
You audit the adjacency structure of a causal graph estimated from a small sample. The world is an
unknown linear-Gaussian DAG with no hidden confounders and full observability. You are given the
correlation matrix, the partial correlation of every pair given all other variables, and the
adjacency set the PC algorithm returned from the same sample. Read the statistics like this: for a
linear-Gaussian DAG, two variables are directly connected if and only if their partial correlation
given all others is non-zero. So a pair with a sizeable partial correlation that PC left
non-adjacent is a likely FALSE NEGATIVE, and a pair PC made adjacent whose partial correlation is
near zero is a likely FALSE POSITIVE. With a small sample PC's independence tests are underpowered,
so borderline values matter. List only the pairs you would genuinely bet on; an empty list is a
valid and often correct answer. Do not restate the whole graph; report edits only. At most 4
removals and 4 additions. Call propose\_skeleton\_edits exactly once.
\end{quote}

\textbf{Post hoc statistical audit.} The ``if and only if'' sentence in the executed prompt is
incorrect for general DAGs. Conditioning on every remaining variable can open collider paths, so
full-order partial correlation may encode an edge of the moral graph rather than an adjacency in
the DAG. We reproduce the prompt because changing it in the paper without rerunning the proposer
would misdescribe the experiment. A valid follow-up should expose separating sets or conditional
independence evidence over multiple conditioning sets and rerun the central proposal arms.

In the semantic condition one sentence is appended: \texttt{The variables are named, and the names
are meaningful: they come from \{domain\}. Use what you know about this domain alongside the
statistics; a pair that is implausible on domain grounds is a good removal candidate even when the
statistics are borderline, and vice versa.} This condition changes both labels and a domain
description, despite the internal run label \texttt{named}.

\paragraph{User payload and output validation.}
The user message is a JSON object containing the variable list and an observational summary with the
row count, marginal moments, correlation matrix, full-order partial-correlation matrix, PC adjacency
list, and currently non-adjacent pairs. Returned skeleton edits are coerced to integer pairs,
range-checked, de-duplicated, and retained only when a removal names a current adjacency or an
addition names a current non-adjacency, while acyclicity is enforced later as each edited skeleton
is oriented. Complete-graph outputs pass through a separate sanitizer that removes self-loops,
duplicates, and conflicting edges and skips directed edges that would create a cycle. When a tool
call is malformed, the model receives at most two repair attempts before the episode continues.
Because the proposal audit in Section~\ref{sec:credit} scores edits after this filtering, it measures
the changes that candidate construction actually received rather than unexecutable text emitted by
the model.

\paragraph{End-to-end baseline.}
For completeness, the end-to-end system prompt states that the target is a directed acyclic graph,
that observational data identify only a Markov equivalence class, and that interventions should be
used to resolve directions. It explicitly says: \texttt{Use undirected\_edges only for genuinely
unresolved adjacencies.} The model receives all observational rows, the remaining budget, and the
mean and standard deviation of every collected interventional batch, and its tool call is validated
before execution. Across the $80$ \texttt{gpt-4o-mini} episodes in Table~\ref{tab:main}, all calls
are valid and none triggers a parser repair, yet every final call contains an empty
\texttt{directed\_edges} list. A representative output submits
\texttt{undirected\_edges=[[0,1],[1,2],[2,3]]} while its rationale describes $X_0$ as influencing
$X_1$ and $X_1$ as influencing $X_2$. Thus the zero directed F1 is a model behavior under this
prompt, not silent rejection by the output sanitizer.

\section{What each proposer actually proposes}
\label{app:edits}

Aggregate edit precision obscures an important asymmetry between removing and adding adjacencies.
The former chooses from PC's estimated skeleton, where spurious edges are rare, whereas the latter
searches its much larger complement for genuine omissions. We therefore evaluate removals and
additions separately against the chance rate of their respective admissible sets
(Figure~\ref{fig:a1} and Table~\ref{tab:decomp}).

The decomposition reveals that proposer quality is expressed primarily as restraint, with lower edit
volume corresponding monotonically to higher overall precision across the five models:
\texttt{gpt-4o-mini} proposes $6.4$ changes per instance and is correct $7.9\%$ of the time, whereas
\texttt{gemini-3-flash} proposes $3.0$ and is correct $32.8\%$ of the time
(Figure~\ref{fig:a1}(c)). Most of this separation comes from restraint in proposing removals because
PC introduces only about $0.1$ spurious adjacency per instance, leaving little genuine opportunity
for deletion, yet the
least selective models attempt $3.3$--$3.7$ removals while \texttt{gemini-3-flash} attempts $0.4$.
Additions present a less hostile base rate because PC misses about $1.75$ true adjacencies; every
model exceeds chance on this action and the between-model spread is correspondingly smaller. Better
proposers thus appear to understand when the evidence is too weak to justify changing an already
competent statistical estimate, even though that selectivity does not reliably improve the final
graph.

anchor and allows model output to define the candidate set. Under this greater authority, final
scores follow the proposal-quality ranking, rising from $0.582$ to $0.671$ at
$n_{\mathrm{obs}}{=}60$ and from $0.712$ to $0.847$ at $300$, while nevertheless remaining below
the corresponding edit-interface score in every case. Model capability is therefore easier to observe when
the model controls the hypothesis space, but the resulting system is less accurate because it also
loses the protection supplied by the statistical estimate. The edit interface masks some genuine
between-model differences as the price of making the assembled system robust to poor generations.

\section{Robustness across design choices}

\section{Edit budget and cost}
\label{app:budget}

\section{Additional results}
\label{app:extra}

Two near-zero ablations help delimit which architectural choices are consequential. Explicitly
adding PC's equivalence class to the edit-derived candidates changes no episode because each of its
members is already an acyclic orientation of PC's skeleton, and the guard reserves half of the
candidate budget for the best-scoring graphs of exactly that form. Similarly, submitting a graph
from edge marginals rather than selecting the highest-weight DAG reproduces the same answer under the
highly concentrated model weights, whose mean maximum is $0.93$ and whose final entropy is $0.23$
nats. These results are not independent algorithmic successes; they show that both operations are
functionally redundant within the implemented pipeline and therefore cannot explain its advantage.

\label{app:ordering}
We also corrected an enumeration asymmetry that could plausibly have hidden the models' strongest
proposal signal. The first implementation listed all removals before additions and truncated the
variant list at six, causing a proposal with four removals to lose most of its additions even though
PC omits many more true edges than it invents. We placed the all-edits variant first, interleaved

capability curve in Section~\ref{sec:credit} therefore cannot be attributed to the ordering artifact,
even though correcting it makes the implemented interface better aligned with where proposal quality
is observed.

\paragraph{What the first draft got wrong.}
Our first submission compared \nem{} against a random editor fixed at the cap of four removals and
four additions and concluded that random edits reproduce the LLM's score. That comparison is not

\section{The corrected interface}
\label{app:promptab}

\begin{figure}[h]
\centering
\includegraphics[width=\linewidth]{nemchua_a7_promptab.pdf}
\caption{The two interfaces on the same $60$ instances with the same five models. Both prompts state
the output mapping identically; they differ in the statistics supplied and in the adjacency rule.}
\label{fig:a7}
\end{figure}

The full-order partial correlation matrix is a sufficient statistic for a Gaussian model, which is
why we supplied it, but its \emph{support} is the moral graph rather than the skeleton. Writing
$\Omega = \Sigma^{-1}$, for a linear-Gaussian DAG $\Omega_{ij} \neq 0$ exactly when $i$ and $j$ are
adjacent or share a child. So the rule we stated --- nonzero partial correlation implies adjacency
--- is false precisely on the co-parent pairs, which are the pairs that carry the unshielded
colliders, and therefore the pairs the orientation problem depends on most.

Figure~\ref{fig:a7} decomposes what changed. Precision \emph{converges} rather than improving: the
spread across models falls from $[0.082, 0.324]$ to $[0.074, 0.178]$. The strongest model loses
most, because it had been complying most. Volume falls for four of five models. And the count of
correct edits found falls sharply for the strong models: \texttt{gemini-3-flash} recovers $58$
correct edits under the misspecified rule and $16$ under the correct one.

That last number is the substantive point, and it is worth stating plainly because it is
counterintuitive. The misspecified rule is a high-recall, low-precision detector for missing
adjacencies: a pair with large full-order partial correlation is either a true edge PC missed or a
co-parent pair, so following the rule finds both. The corrected rule points the model at PC's
separating sets --- but those are exactly the computations PC already performed to build the
skeleton, so the model is being asked to overturn a decision using the evidence that produced it.
The information available to a proposer is not a property of the data alone; it is a property of
what the front-end has already consumed. A statistically incorrect interface can expose more of it
than a correct one.

\section{The statistical ranker}
\label{app:ranker}

\begin{figure}[h]
\centering

\label{fig:a8}

The ranker is the instruction in our prompt, executed without a model:

\begin{quote}\small\ttfamily
remove = argsort(|pcorr[e]| for e in pc\_adjacencies)[:k]\\
add ~~~= argsort(-|pcorr[e]| for e in non\_adjacent)[:k]
\end{quote}

Table~\ref{tab:ranker} places it against the LLM at every stage of the pipeline. It wins at every
stage, and the margin widens upstream: the ranker puts the true DAG inside the hypothesis set on
$87.5\%$ of main-cohort instances against the LLM's $68.1\%$, and raises the best F1 available in
the set from $0.967$ to $0.985$. This matters for interpretation --- the ranker is not winning
through a lucky interaction with the selector, it is winning by constructing a better hypothesis
space, which is the job the proposer was given.

\section{Enumeration saturation at \texorpdfstring{$d=12$}{d=12}}
\label{app:saturation}

At $d{=}12$ the ordering of the whole ladder inverts, and the cause is the candidate budget rather
than the proposals. Handing the pipeline the \emph{true} skeleton gives skeleton F1 $0.991$ but a
best-available F1 inside the hypothesis set of only $0.918$, and a final score of $0.883$. Keeping
PC's own skeleton (F1 $0.941$) yields a best-available F1 of $0.939$ and a final score of $0.930$.

A better skeleton is being punished. The reason is that $M=48$ candidates cannot represent the
orientation space of a $12$-node skeleton: with more true adjacencies there are more orientations to
cover, the subsample thins, and the true DAG is less likely to survive into the set. Truth-in-set is
$0.40$ for both the true-skeleton and LLM arms, but the LLM's smaller skeleton concentrates its
budget on fewer orientations.

This bounds the paper's scope honestly. Every claim we make about proposal quality holds in the
regime where the exact posterior can be enumerated, which for our budget is $d \leq 10$. Beyond it,
proposal quality stops being the binding constraint and the representation does. A system intended
for larger graphs would need an approximate posterior, and the attribution question would have to be
re-asked there.

\section{Adjacency ceiling and orientation ceiling}
\label{app:ceiling}

\begin{figure}[h]
\centering
\includegraphics[width=\linewidth]{nemchua_a9_ceiling.pdf}
\caption{Perfect four-edit repair against the true adjacency set at any edit distance. On synthetic
instances they coincide; on published structures they do not.}
\label{fig:a9}
\end{figure}

\texttt{perfect edits} repairs PC's skeleton within the same four-edit budget the LLM has.
\texttt{true skeleton} hands over the true adjacency set however far it is from PC's. The difference
separates two failure modes that are easy to conflate: a proposal budget too small to express the
repair, and an orientation problem that no adjacency information can solve.

On synthetic instances the two are identical to three decimals on every cohort ($p=1.0$ on the main
cohort): PC makes at most four adjacency errors, so the budget never binds, and everything the
oracle leaves on the table is orientation error. On the published structures the budget binds hard
--- $0.962$ against $0.890$ at $n_{\mathrm{obs}}{=}60$, $0.966$ against $0.921$ at $300$ --- because
those graphs are denser and PC makes more than four errors. This qualifies a claim we made in the
first draft: on \texttt{sachs} the oracle's low score is \emph{not} mainly an orientation failure.
Perfect four-edit repair reaches $0.467$, barely above the $0.411$ of proposing nothing; the true
skeleton reaches $0.828$. So $0.36$ of the gap is adjacency error the budget cannot express and
$0.17$ is orientation error that no adjacency information removes. The earlier attribution to
orientation sampling alone was wrong about the larger term.

\section{Limitations}
\label{app:limitations}

\paragraph{The corrected interface is one correction, not the space of them.}
Section~\ref{sec:mechanism} replaces the misspecified adjacency rule with PC's separating sets and
the correct criterion, and finds the deficit unchanged. That rules out the specific objection that
our negative result is an artifact of telling the model something false. It does not rule out the
general one: bootstrap stability, partial correlations over many conditioning sets, or a design that
lets the proposer request a test rather than read a matrix are all untried, and the analysis in
Appendix~\ref{app:promptab} gives a positive reason to expect them to differ --- what a proposer can
add depends on what the front-end has already consumed, so interfaces that expose statistics PC does
not use are the ones worth trying next. Our claim is bounded to two interfaces, and both are
reported.

\paragraph{The permutation control matches counts, not structure.}
The matched-count null in Section~\ref{sec:credit} fixes how many removals and additions a random
editor makes, and draws them uniformly from PC's adjacency set and its complement. It therefore
isolates proposal content from proposal volume, which was the confound in our first draft, but it
does not condition on \emph{which} edges are plausible: a proposer that concentrates its edits on
high-degree nodes, or on pairs with borderline test statistics, is being compared against one that
does not. The statistical ranker is the strongest version of that objection we could construct, and
the LLM loses to it; a null drawn from the ranker's own distribution rather than the uniform one
would be a sharper test still.

\paragraph{The semantic contrast is confounded.}
The semantic condition changes both variable labels and a domain description, and all five networks
are established benchmarks that may have been memorized during pretraining. Model episodes also
reuse the same base parameterizations, making episode-level observations within a base instance
dependent across proposers. The current comparison can therefore establish an association between
semantic presentation and proposal quality, but it cannot identify which source of information
caused that association. Shuffled labels, separate label and description factors, novel domain
graphs, and cluster-aware inference are required before attributing the difference to transferable
domain knowledge.

\paragraph{The decision layer is approximate and does not scale.}
BIC weights approximate model evidence, parameters are point estimates, expected information gain
uses Monte Carlo, and only $48$ candidate DAGs survive. Orientation enumeration becomes sampling at
larger $d$, allowing the filter to miss the truth even when an edit repairs the skeleton. These
approximations interact rather than fail independently: candidate omission cannot be repaired by
better intervention selection, while concentrated weights can hide the omission by expressing high
confidence only within the retained set. A large final maximum weight is therefore evidence of
concentration inside a truncated fitted model, not calibrated evidence that the selected DAG is
correct in the unrestricted graph space.

\paragraph{One model class, one front-end.}
All results assume linear-Gaussian mechanisms, causal sufficiency, full observability, hard
interventions, and a PC observational estimate. Varying sample size and PC's significance threshold
changes the amount of residual error but not its qualitative source. Other estimators, nonlinear or
non-Gaussian mechanisms, latent confounding, or soft interventions may leave a different error
pattern and alter both the value of semantic knowledge and the downstream likelihood. Transporting
our conclusions to those settings therefore requires repeating the same proposer-replacement audit.
